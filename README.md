# ML Pipelines

This project is divided into two parts:

1. Use tree-based methods and neural networks to analyze the **UCI Adult Income Dataset**, which predicts whether an individual's annual income exceeds $50K/year based on census data.

2. Build an unsupervised pipeline to classify songs in a **Kaggle Spotify dataset** into genres using a combination of features, dimensionality reduction, and clustering methods.

### Data sources: 
- **UCI Adult Income Dataset:** [Adult](https://archive.ics.uci.edu/dataset/2/adult)
- **Kaggle Spotify Tracks Dataset:** [Spotify Tracks Dataset](https://www.kaggle.com/datasets/maharshipandya/-spotify-tracks-dataset)
